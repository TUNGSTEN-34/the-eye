# The Eye — Analyst

A responsive, dark-blue public information portal concept with sections for:
- Home and platform introduction
- Public-data dashboard preview
- Editorial/news placeholders
- Learning resources
- About and editorial principles
- Article/idea submission form preview

## Run locally
Open `index.html` in a browser. No build step or package installation is required.

## Important status notes
- Dashboard metrics are placeholders; no live data feed is connected.
- News cards are sample explainer topics, not published reporting.
- The submission form only displays a local confirmation preview. It does not send or store personal information.
- Before production use, connect verified data sources and a secure backend for article submissions, with suitable privacy and spam protections.

## Deploy
Import this repository into Vercel. The static site can deploy from the repository root without a build command; set the output directory to the repository root if prompted.
